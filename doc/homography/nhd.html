Description

Computing the plane to plane homography without fancy thing such as inversion of big matrix or eigenvalues.
In here it will be present method in step-by-step manner where every step has some geometric meaning.

Nomenclature

2D Euclid vector

Ordered pair of two real numbers.
p = ( x, y ) = [x,y] T; x,y ∈ ℝ

2D Homography point

Ordered triplet of three real numbers.
p = ( x, y, z ) = [x,y,z] T; x, y, z ∈ ℝ

Homography

H: ℝ2 → ℝ2
Definition: project (first) plane to (second) plane.
Matrix form Algebraic form
h11 h12 h13
h21 h22 h22
h31 h32 h33
     
x' =
x·h11 + y·h12 + h13
x·h31 + y·h32 + h33

y' =
x·h21 + y·h22 + h23
x·h31 + y·h32 + h33

Problem

What we have:

  • s0, sx, sy, sz ∈ ℝ2
  • t0, tx, ty, tz ∈ ℝ2
  • o=(0,0)
  • area( si, sj, sk ) ≠ 0; i ≠ j ≠ k; i, j, k ∈ { 0, x, y, z }
  • area( ti, tj, tk ) ≠ 0; i ≠ j ≠ k; i, j, k ∈ { 0, x, y, z }
  • Nice to have:
    | area( ti, tj, tk ) | ≤ area( t0, tx, ty ); i, j, k ∈ { 0, x, y, z }
    | area( si, sj, sk ) | ≤ area( s0, sx, sy ); i, j, k ∈ { 0, x, y, z }

What we want:

  • H is homography.
  • ti = H ( si ); i ∈ { 0, x, y, z }

Simple Homography

(0,0) = P(0,0);
(1,0) = P(1,0);
(0,1) = P(0,1);
(X,Y) = P(1,1);
Homography matrix:
X 0 0
0 Y 0
1-Y 1-X X+Y-1
0 ≠ (1-Y)2 + ( 1-X )2 + ( X+Y-1 )2
Always ≠ 0.
Always exists.
If we observe as function we have minimum at (X,Y)=(2/3,2/3).

... and vice versa

(0,0) = P(0,0);
(1,0) = P(1,0);
(0,1) = P(0,1);
(1,1) = P(X,Y);
Homography matrix:

0 X · (X + Y - 1) 0

(X,Y) ≠ (1,0)

Constraints

If we use any tree point and try to make affine transform those tree points must make triangle with non zero area.

For higher dimension constraints are similar. Any volume must be non zero.
3d:
  • volume( si, sj, sk, sl ) ≠ 0; i ≠ j ≠ k≠ l; i, j, k, l ∈ { 0, 1, 2, 3 , 4 }
  • volume( ti, tj, tk, tl ) ≠ 0; i ≠ j ≠ k≠ l; i, j, k, l ∈ { 0, 1, 2, 3 , 4 }
Additional requirements previously mentioned are sub set of this one.

Off topic

Homography matrix can be multiplied by some non zero factor for better utilization.
Here are several proposed values to do that:
λ = 1/h33
This is one of the most common way to do. Numerical error may occur if h33 is very small comparing to h31 and h32
λ= s/||h3·||, s ∈ ℝ s ≠ 0;
Another common way to do. s i usually equal to 1.
λ= s/||h*1||, s ∈ ℝ s ≠ 0;
Observe first column as 3D vector. s i usually equal to 1. First column can be seen as first basis vector of first plane.
λ= 1/||h*1 ⨯ h*2||
h*1 ⨯ h*2 is normal of source plane.
λ = 1/|| vx·vx + vy·vy||; v = h*1 ⨯ h*2;
This cross product also give equation of horizon or vanish line on target plane( z=1 ).
First and second coordinate will present direction of line in form: x·cos( α ) + y·sin( α ) - r = 0
λ= h*3 · ( h*1 ⨯ h*2 )
Distance of plane from origin.
